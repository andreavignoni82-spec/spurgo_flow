# Configurazione Geoapify — Spurgo Flow 6.1.7

1. Crea un account Geoapify.
2. Crea un progetto.
3. Copia la API key generata.
4. Apri `geocoding-config.js`.
5. Sostituisci:
   `INSERISCI_GEOAPIFY_API_KEY`
   con la tua chiave.
6. Carica il file aggiornato su GitHub insieme a tutti gli altri file.

La chiave può essere limitata per origine/referrer dal pannello Geoapify.
La versione gratuita prevede fino a 3.000 richieste di geocoding al giorno secondo la documentazione Geoapify.
