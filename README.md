# Spurgo Flow Beta v0.1

Prototipo statico PWA per gestione interventi di una ditta di spurghi.

## Funzioni demo
- Accesso Ufficio / Operatore
- Dashboard interventi
- Creazione e assegnazione intervento
- Agenda operatori
- Smartphone operatore
- Navigazione / chiamata
- Avvio intervento con timer
- Dettatura vocale dove supportata
- Relazione tecnica demo
- Attività / anomalie
- Chiusura intervento
- Storico cliente e memoria tecnica
- Persistenza locale con localStorage

## Pubblicazione GitHub Pages
1. Crea un repository GitHub, ad esempio `spurgo-flow-beta`.
2. Carica tutti i file nella root del repository.
3. Vai in Settings > Pages.
4. In Build and deployment seleziona Deploy from a branch.
5. Seleziona `main` e cartella `/root`.
6. Salva e apri l'URL generato da GitHub Pages.

La Beta è interamente frontend e non richiede server o database.
